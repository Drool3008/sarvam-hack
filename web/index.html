Family Health Agent

The household agent that keeps an ageing parent's medicines and appointments running.

checking backend…

1Talk to the agent

Speak or type the way you would to family. The agent keeps your exact words, works out a tier, and answers out loud in your own language.

2The agent calls the clinic

The agent speaks to the receptionist, holds the slot, then hands the parent the line so they confirm their own appointment by name.

Built on Sarvam AI — Saaras v4 (verbatim), sarvam-105b, Mayura v1, Bulbul v4 Flash, sarvam-105b-conversations. The agent never names a condition, never suggests a dose and never substitutes a medicine; each of those goes to a human. API docs · audit trail
